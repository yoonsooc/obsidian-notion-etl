# 코드리뷰 체크리스트

[Uber Go 스타일 가이드](https://github.com/TangoEnSkai/uber-go-style-guide-kr/blob/master/README.md)에서 이 프로젝트에 적용되는 18개 항목을 추린 것이다 (2026-08-21 사용자 승인). 마일스톤별 코드리뷰는 이 문서를 기준으로 수행한다.

## 필수 (정확성/안전)

1. **에러 처리**: 에러 래핑은 `fmt.Errorf("...: %w", err)`. 같은 에러를 로그와 반환으로 이중 처리하지 않는다. 에러 메시지는 소문자로 시작하고 마침표를 붙이지 않는다.
2. **패닉 금지**: panic을 사용하지 않는다. 예외는 초기 설정 로딩(.env, base.config.yaml 누락) 단계뿐이다 (PRD 6.2와 일치).
3. **종료는 main에서**: `os.Exit`, `log.Fatal`은 main 함수에서 한 번만 호출한다. 라이브러리 코드(internal/)에서는 에러를 반환한다.
4. **고루틴 fire-and-forget 금지**: 모든 고루틴은 종료 시점이 보장되어야 한다 (WaitGroup 등).
5. **타입 어설션**: `v, ok := x.(T)` 형태로만 사용한다. 단일 반환 형태는 패닉을 유발하므로 금지.
6. **defer 정리**: 리소스 해제(`resp.Body.Close()`, 파일 닫기)는 defer로 수행한다.
7. **채널 크기**: 채널 크기는 0 또는 1이 기본. 그 외 크기는 근거를 주석으로 남긴다.
8. **변경 가능한 전역변수 금지**: mutable 패키지 전역 대신 구조체 필드로 주입한다.
9. **init() 금지**: 패키지 init 함수를 사용하지 않는다.
10. **시간 타입**: 시간은 `time.Time`, 기간은 `time.Duration`으로 다룬다. int 초/문자열 비교 금지 (설정 파일 직렬화 경계 제외).

## 권장 (가독성/일관성)

11. **필드 태그**: 직렬화되는 구조체(JSON/YAML)는 모든 필드에 태그를 명시한다.
12. **중첩 감소**: 에러/특수 케이스를 먼저 처리하고 일찍 반환한다. 불필요한 else를 제거한다.
13. **변수 스코프 최소화**: 가능하면 `if err := ...; err != nil` 형태로 스코프를 줄인다.
14. **import 그룹**: 표준 라이브러리 / 외부 패키지 두 그룹으로 분리한다.
15. **패키지 이름**: 소문자, 단수, 언더스코어 없이. `util`, `common` 같은 무의미한 이름 금지.
16. **구조체 초기화**: 필드명을 명시하여 초기화한다 (`Foo{Name: "x"}`).
17. **컨테이너 용량**: 크기를 아는 slice/map은 `make`에 용량 힌트를 준다.
18. **도구 통과**: `gofmt -l`과 `go vet ./...` 통과를 기본 전제로 한다.

## 프로젝트 (도메인 어휘)

Uber 가이드 외 프로젝트 고유 항목이다. 근거와 상세 규칙은 CLAUDE.md의 "도메인 어휘 규칙" 섹션에 있다.

19. **도메인 어휘**: 타입/필드 어휘는 입출력 위치가 아니라 데이터가 속한 도메인(glossary)을 따르고, 산출물 타입은 `Draft` 접미사를 쓴다. `internal/vault`에 Notion 어휘, `internal/notion`에 Obsidian 어휘가 등장하면 안 된다 (혼용은 변환 패키지에서만 허용). 검증: `grep -rni "notion" internal/vault/*.go`와 `grep -rniE "obsidian|frontmatter|vault" internal/notion/*.go`에서 `_test` 제외분이 비어 있어야 한다. 불변식의 대상은 식별자·타입·주석의 결합이며, 테스트 픽스처의 **데이터 값**(예: url 속성 테스트의 `obsidian://` URI — 커스텀 스킴 허용을 검증하는 실제 값)은 예외다.
