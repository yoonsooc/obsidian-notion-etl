## 주석 정리 규칙 (에이전트 공통)

- 패키지 doc 주석: 영문 1~2줄
- exported 심볼: godoc 규약의 영문 한 줄 (필수 제약은 짧게 유지)
- unexported: 비자명한 경우만 영문 한 줄
- 제거: PRD 절/결정 번호(D6 등)/task 문서/리뷰 번호 참조, 날짜, 변경 서사
- 유지(압축해서): NFC/NFD 정규화 이유, obsidian:// 인라인 링크 거부,
  Rate Limit 근거, O_EXCL/원자적 쓰기 이유 같은 비자명 제약
- 코드/문자열 리터럴(한국어 에러·로그 메시지, 테스트 이름) 변경 금지
- gofmt / go vet / go test 통과 필수
