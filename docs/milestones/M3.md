# M3 리뷰 (backup: Notion → Obsidian 증분 백업)

기간: 2026-08-30 (1일)
상태: 완료. 실환경 E2E 통과 — 전체 백업 70건 성공(경고 0), 재실행 시 증분 0건(워터마크 동작) 확인

## 산출물

- `backup.go`: FR-3 전체 흐름 조립. --dry-run 플래그, 워터마크 증분 조회, 파일명 파생
  (Date → 제목 → 페이지 ID, 실행 내 충돌 -2/-3 접미사), 순차 처리(동시성 없음 — 처리량은
  Limiter가 지배하므로 워커 풀 불필요), 전건 성공 시에만 워터마크 갱신(FR-3.6)
- `internal/notion/query.go`: 읽기 측 API. `QueryPagesSince`(last_edited_time on_or_after 필터
  + 오름차순 정렬 + 커서 페이지네이션), `ListBlockChildren`(커서 페이지네이션, v1은 최상위만),
  `Page` 타입(제목은 스냅샷 속성명 조회 실패 시 title 타입 스캔 폴백)
- `internal/notion/blocks.go` 확장: `RichText.PlainText`(읽기 응답 전용), `Block.HasChildren`,
  `Block.UnmarshalJSON` — 미지원 타입(quote, numbered_list_item 등)의 rich_text를 `Fallback`
  필드로 추출해 역변환의 plain text 폴백을 가능하게 함. `JoinPlainText` 헬퍼
- `internal/markdown/render.go`: `FromBlocks` — ToBlocks의 역방향(D4). heading/to_do/bullet/
  paragraph 매핑, 미지원 타입은 텍스트 추출 시 문단 폴백 + 경고, 추출 불가 시 스킵 + 경고,
  중첩 블록 경고. nil 본문 가드가 형태 이상 입력의 패닉을 방지
- `internal/vault/write.go`: `NoteDraft`(D13: Page → **NoteDraft**, Draft 접미사 규약의 첫 실전 적용),
  `WriteNote`(원자적 쓰기, 무조건 덮어쓰기 D3), `SanitizeFileName`(금지 문자 `-` 치환)
- main.go: backup 서브커맨드 배선, usage 갱신
- 테스트 12건 추가: query 페이지네이션/필터 유무/title 타입 스캔 폴백, 블록 Unmarshal 폴백,
  FromBlocks 매핑·폴백·스킵·중첩 경고·plain_text 우선, WriteNote 왕복(자체 파서로 재파싱)·
  덮어쓰기·빈 파일명, SanitizeFileName 테이블

## 설계 결정

- **D13 준수**: 입력은 notion 어휘(`Page`, `Block`), 산출물은 obsidian 어휘(`NoteDraft`).
  역변환은 이중 언어 허용 패키지인 markdown에 두었다(ToBlocks와 동거, 별도 패키지는 과함).
  vault/notion의 단일 언어 불변식은 유지 (notion_* frontmatter 키는 main이 주입하는 데이터 값)
- **플러그인 비관여**: backup은 변환 정책이 없는 미러링이라 Plugin 계약과 무관하게 동작.
  역방향 커스텀 변환이 필요해지면 그때 인터페이스 확장을 검토
- **미지원 블록의 폴백 지점**: 타입별 구조체가 없는 블록의 텍스트 추출은 렌더러가 아니라
  Unmarshal 시점(Block.Fallback)에서 처리 — Block 구조체가 읽기/쓰기 겸용이 되면서
  json:"-"로 쓰기 페이로드 오염을 차단
- **워터마크 안전성**: on_or_after(포함 비교)라 경계 페이지가 재처리될 수 있으나 덮어쓰기라
  안전. 실행 시작 시각 기준이므로 실행 중 수정분도 다음 실행에서 잡힘
