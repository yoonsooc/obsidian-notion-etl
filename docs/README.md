결정에는 D번호가 붙어 있고, D1~D16의 원문은 동결된 PRD의 Decision Log에, D17부터는
decisions/의 개별 문서에 있습니다. M1/M2의 tasks/에는 태스크 단위의 계획·변경 이력이
남아 있습니다.

관리 정책 (2026-09-03 결정): PRD는 v1 프로토타입 기록으로 동결합니다. 이후의 기능 추가와
수정은 (1) 결정이 필요한 사안은 decisions/에 ADR 한 건씩, (2) 구현 작업은 milestones/에
마일스톤 문서로 기록하는 이원 체계로 관리합니다.

경로·계정 등 개인 정보는 공개 전환 시 자리표시자로 마스킹했습니다.
