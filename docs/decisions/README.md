# 설계 결정 (ADR)

v1 프로토타입 이후의 설계 결정을 한 건당 한 파일로 기록합니다. D1~D16은 동결된
[PRD](../PRD.md)의 Decision Log에 있고, 여기서는 **D17부터** 번호를 이어갑니다.

## 형식

파일명: `D17-짧은-슬러그.md`

```markdown
# D17: 제목

날짜: YYYY-MM-DD
상태: 채택 | 대체됨(D##) | 폐기

## 맥락
무엇이 문제였고, 어떤 제약이 있었는가.

## 결정
무엇을 하기로 했는가 (한 문단).

## 근거와 대안
왜 이것인가. 검토했지만 택하지 않은 대안과 그 이유.

## 영향
바뀌는 코드/운영/문서. 관련 마일스톤 문서 링크.
```

결정이 뒤집히면 원문을 고치지 않고 새 ADR을 만들어 이전 것의 상태를 "대체됨"으로
표시합니다. 원칙은 PRD 시절과 같습니다: 기록은 추가만 하고 다시 쓰지 않습니다.
